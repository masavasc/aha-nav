# AHA 2026 当日ナビ

AHA Scientific Sessions 2026（McCormick Place, Chicago）の当日用ページです。GitHub Pages に置いてスマホで開きます。

- 今の予定・次の予定と、出発すべき時刻（シカゴ時間）
- メモの「9:17 に抜けて」のような時刻を読んで、抜ける時刻を知らせる
- 位置情報（GPS）で、今いる建物と、行き先の建物の方向・距離を表示（コンパス対応）
- 館内の道順（階の移動、Grand Concourse など）と、建物の立体図に行き先の印
- 一度開けば、電波が弱くても館内図ごと開ける（Service Worker）

## 置き方（GitHub Pages）

1. GitHub で新しいリポジトリを作る（例: `aha-nav`）。
2. このフォルダの中身（`index.html`、`sw.js`、`maps/`、この README）をそのままアップロードする。
3. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして Save。
4. 数分後に `https://<ユーザー名>.github.io/aha-nav/` で開けるようになる。スマホで開いて「ホーム画面に追加」。

位置情報は https のページでしか使えません。GitHub Pages は https なのでそのまま使えます。

## 予定の入れ方

予定はページに入っていません（公開リポジトリに予定を載せないため）。

1. スマホでプログラム検索アプリを開き、マイリストの「当日ナビで開く」を押す。当日ナビが開き、予定が自動で入る（予定は URL の `#plan=` に乗せて渡し、取り込んだあと URL から消す）。
2. うまくいかないときは「当日ナビ用にコピー」を押し、当日ナビの「予定を取り込む」に貼り付けて「取り込む」。
3. 予定を変えたら、同じ手順でもう一度取り込む（前の予定は置き換わる）。前から開いていたタブも、戻ったときに新しい予定に切り替わる。
4. iPhone で「ホーム画面に追加」したアプリは Safari と保存場所が別なので、「当日ナビで開く」では入らない。検索アプリで「当日ナビ用にコピー」を押してから、ホーム画面のアプリで「クリップボードから取り込む」を押す（貼り付けの許可を聞かれたら許可する）。

予定はスマホのブラウザの中だけに保存されます。

## 注意

- 建物の位置は OpenStreetMap の輪郭、館内図は McCormick Place の立体図をもとにした目安です。
- 屋内では GPS が数十 m ずれることがあり、何階にいるかはわかりません。階は道順の文を見てください。
- iPhone のコンパスは「コンパスをオン」を押したときに許可を求められます。
